# ResQBot
### Vision-Guided Search and Rescue Robot Simulation

ResQBot is a Python-based robotics simulation designed to demonstrate
autonomous navigation, visual perception, obstacle avoidance and
intelligent path planning in a virtual rescue environment.

## Objectives
- Simulate a mobile search and rescue robot.
- Detect obstacles and designated targets using computer vision.
- Generate navigation paths using the A* algorithm.
- Demonstrate autonomous robot movement.
- Evaluate navigation performance.

## Technology Stack
- Python
- Pygame
- OpenCV
- NumPy
- Matplotlib

## Project Status
Initial development.

## Installation
1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies using pip install -r requirements.txt.
4. Run the application using python main.py.
